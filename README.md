# EGOR CASINO

Фан-казино на вымышленные **Егорики**: 8 столов, прогрессия, косметика, пасхалки и режим
**«Заработок»** — кликер «Ботать в БГУИР». Один игрок, всё хранится в `localStorage`,
сервера нет. «Онлайн», чат и лента выигрышей генерируются на клиенте.

## Как запустить

Открыть `index.html` в браузере — и всё. Сборки нет, зависимостей нет, работает и с диска
(`file://`), и на GitHub Pages. Шрифты (Russo One, Onest, JetBrains Mono) грузятся с Google Fonts;
без интернета подставятся системные.

### Публикация: https://egoricon.github.io/ecasin/

Все пути в проекте относительные, поэтому сайт работает из подпапки `/ecasin/` без правок.
1. Файлы проекта лежат в корне ветки `main` (рядом с `index.html` — папки `css/` и `js/`).
2. GitHub → **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*,
   Branch — `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты сайт открывается по ссылке. Пустой файл `.nojekyll` отключает лишнюю обработку Jekyll.

Тесты (нужен Node 18+):

```bash
npm test          # правила игр, экономика, миграция сейвов, кликер — node --test
npm run e2e       # прогон в настоящем Chromium (нужен playwright)
```

Скрипты — обычные `<script defer>`, а не ES-модули: так проект работает прямо с диска.
Каждый файл кладёт свою часть в общий объект `EC` (`EC.config`, `EC.rules.poker`, `EC.econ` …).

## Главные правила архитектуры

1. **Одна валюта** — `state.balance`. Казино и «Заработок» пишут в одно поле.
2. **Сейвы не ломаются.** `load()` мержит сохранённое поверх `DEF()`: новое поле просто
   добавляется в `DEF()` в `store.js`. Старые сейвы (достижения и магазин массивами) мигрируют сами.
   Ключ `localStorage` тот же, что был: `egor-casino-v3`.
3. **Контракт раунда.** Ставка списывается ДО анимации, выплата — ПОСЛЕ:
   ```js
   const round = EC.econ.beginRound('dice', bet);  // списал ставку, пометил незавершённый раунд
   round.add(extra);                               // дабл/сплит/рейз
   round.end(pay, { label });                      // pay = ставка + выигрыш (0 — проигрыш) → settle()
   ```
   `settle()` считает статистику, XP, VIP, достижения, квесты, титулы и шлёт события `win/loss/push`.
   Пока раунд идёт, уйти со стола нельзя. Если закрыть вкладку посреди раунда — ставка вернётся.
4. **UI не лезет в экономику.** Экономика шлёт события в `EC.bus` (`note`, `win`, `change`,
   `bankrupt`), интерфейс на них подписан.
5. **Дизайн — только токены.** Акцент (`--accent`) розовый в казино и лаймовый в «Заработке»
   (`<body data-mode>`), числа — `--info` моноширинным, золото (`--win`) — только в момент выигрыша,
   проигрыш — `--loss`. Hex-цвета в компонентах не пишем.

### Как добавить игру

1. Правила без DOM — `js/rules/<игра>.js` (+ тест в `tests/`).
2. Экран — `js/games/<игра>.js`: `EC.shell.mount(root, { id, table, extra, primary })` даёт
   панель ставки, `ctx.readBet()`, `ctx.result()`, автоигру; дальше `beginRound` → `round.end`.
3. Строка в `C.GAMES` в `config.js` и `<script>` в `index.html`.

## Что исправлено относительно прошлой версии

- **Слоты печатали деньги:** RTP был 337% (Классика) и 628% (Книга Егорика). Математика пересчитана
  скриптом (`tests/slots-rtp.test.js`): теперь ≈ 95.8% / 96.9% / 96.4% (Мегавейс — с учётом серии).
  Бонус («ЕГОРИК на каждом барабане») выпадает примерно раз в 180 спинов (в Книге — раз в 520),
  а не раз в десятки тысяч. Выигрыш бонус-игры теперь проходит через `settle()` (ивент, статистика, VIP).
  «Triple 777» больше не выдаётся за бонус — только за три 777.
- **Баккара:** настоящая таблица добора третьей карты банкира (раньше обе стороны брали на <6).
  Ничья платит 8:1 (раньше фактически 7:1).
- **Холдем → честный Ultimate Texas Hold'em:** блайнд платит со стрита (1:1 … 500:1), ниже — пуш;
  одна ставка «Плей» за раздачу (раньше можно было «рейзить» несколько раз и терять деньги),
  обязательный выбор ×1/фолд на ривере, квалификация дилера с пары, раунд идёт через `settle()`.
- **Оценщик рук:** правильные кикеры (каре + пара + туз, три пары).
- **Настоящие колоды** вместо «бесконечной»: в видеопокере больше не бывает двух одинаковых карт.
  Блэкджек — шуз из 6 колод, баккара — из 8.
- **Блэкджек:** появился обещанный сплит, дилер проверяет блэкджек при тузе/десятке,
  дилер не добирает, если игрок уже перебрал.
- **Недельный ивент** умножает только чистый выигрыш: ничья больше не приносит прибыль.
- **Видеопокер:** кнопка «Играть»/пробел работает (раньше вела в никуда).
- Escape больше не выкидывает со стола посреди раунда; навигация во время раунда заблокирована.
- Имя игрока экранируется (раньше его можно было «сломать» кавычкой).
- Сохранения из файла проходят ту же проверку, что и обычная загрузка.
- Сохранены старые фиксы: поворот рулетки считается от текущего угла колеса; модалка имени при
  первом входе и после сброса не закрывается без имени; «Итог сессии» не вернулся.

## Режим «Заработок»

Переключатель в шапке. Лаймовый режим, туториал при первом входе (можно повторить в настройках),
клик-зона «Ботать», 10 апгрейдов в двух вкладках: **Учёба** (+к клику) и **Быт** (+к пассивному доходу).
Цена уровня: `base · 1.3^уровень`, покупка ×1 / ×10 / максимум. 3% шанс «автомата» — клик ×5.

Пассивный доход считается по времени, а не по тикам: пока вкладка открыта — 100%,
пока скрыта или закрыта — 50% и не больше 8 часов. Часы, переведённые назад, ничего не дают.

Решения по открытым вопросам из карты проекта (все цифры — в `C.EARN` в `config.js`):

- **Сила клика** — 1 E на старте, кликер «небыстрый»: при ~2 кликах в секунду 1 000 E ≈ 2 минуты,
  10 000 ≈ 7 минут, 100 000 ≈ 23 минуты. Магазин (1 200–12 000 E) не обесценивается,
  но после банкротства есть куда пойти.
- **Потолка нет** — честный бесконечный idle с экспоненциальными ценами.
- **Своя прогрессия есть:** 4 достижения, 2 титула (Ботан, Отличник БГУИР), миссия, ежедневный квест
  на клики, навык «Зубрила» (+10% к доходу) и отдельный блок в статистике.

## Коды (Настройки → Коды)

`money`, `bonus`, `super`/`win10`, `mega`/`win100`, `ultra`/`win1000`, `bankrupt`, `gorilla`, `boss`,
`kalyadka`, `vip3`. Горилла ещё прячется в лайв-чате. Имя «Егор» при первом входе даёт +10 000 E.

## Клавиатура

Пробел — главное действие стола · T — турбо ×1/×2/×4 · Esc — закрыть окно ·
блэкджек: 1 взять, 2 стоп, 3 дабл, 4 сплит · видеопокер: 1–5 держать карту.
