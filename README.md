# EGOR CASINO

Сайт: **https://egoricon.github.io/ecasin/**

Игра начинается не в казино, а в строгом сине-белом кликере **«Сессия в БГУИР»**: ботаешь,
копишь Егорики, покупаешь конспекты и кофе. Всё это время на экране висит тёмная дверь
**«Подвал общаги»** с растущими слухами. Наботал 40 000 — покупаешь пропуск за 10 000,
свет гаснет, загорается неон — и открывается **казино**. Внутри столы открываются с уровнем.
Проигрался — «Отчислен из казино», возвращаешься ботать. Петля: учёба кормит казино,
казино даёт азарт и цели, банкротство возвращает к учёбе.

Один игрок, всё хранится в `localStorage`, сервера нет. «Онлайн», чат и лента выигрышей
генерируются на клиенте. Егорики вымышленные.

## Как запустить

Открыть `index.html` в браузере — и всё. Сборки нет, зависимостей нет, работает и с диска
(`file://`), и на GitHub Pages (все пути относительные, сайт живёт в подпапке `/ecasin/`).

```bash
npm test                   # правила игр, экономика, миграция сейвов, учёба, баланс — node --test
npm run e2e                # весь путь игрока в настоящем Chromium (нужен playwright)
node tools/balance-sim.js  # темп учёбы: активный и ленивый игрок против целей роадмапа
```

### Публикация

GitHub Pages публикует ветку `main` из корня (Settings → Pages → Deploy from a branch → `main`, `/ (root)`).
Любой пуш в `main` через 1–2 минуты появляется на сайте. `.nojekyll` отключает лишнюю обработку.

Скрипты — обычные `<script defer>`, не ES-модули: так проект работает прямо с диска.
Каждый файл кладёт свою часть в общий объект `EC` (`EC.config`, `EC.rules.poker`, `EC.econ` …).

## Главные правила архитектуры

1. **Одна валюта** — `state.balance`. Учёба и казино пишут в одно поле.
2. **Сейвы не ломаются.** `load()` мержит сохранённое поверх `DEF()`; новое поле просто добавляется
   в `DEF()`. Ключ `localStorage` прежний: `egor-casino-v3`. Сейвы до версии 2 мигрируют сами:
   кто уже играл в казино или копил (`games > 0` или `balance > 100`) — **ветеран**: казино открыто,
   обучения и сцены нет, столы до его уровня доступны, прогресс не теряется.
3. **Производные значения не хранятся.** Сила клика и доход в секунду считаются из уровней
   апгрейдов (`getClickPower()`, `getEps()`); все множители — в одном месте.
4. **Контракт раунда.** Ставка списывается ДО анимации, выплата — ПОСЛЕ:
   ```js
   const round = EC.econ.beginRound('dice', bet);  // списал ставку, пометил незавершённый раунд
   round.add(extra);                               // дабл/сплит/рейз
   round.end(pay, { label });                      // pay = ставка + выигрыш (0 — проигрыш) → settle()
   ```
5. **Темы — только токены.** `<html data-theme="bsuir|neon">` определяется режимом. Переключить в
   консоли: `document.documentElement.dataset.theme = 'bsuir'`. Hex-цвета есть только в `tokens.css`.
   В неоне акцент розовый, числа — `--info`, золото — только в момент выигрыша. В БГУИР — одна синяя
   краска, шрифты PT Serif/Sans/Mono, никакого свечения; дверь в подвал — единственный тёмный элемент.
6. **Всё в конфиге.** Цены, пороги, уровни столов — таблицы в `config.js`, логика их только читает.

### Как добавить игру

1. Правила без DOM — `js/rules/<игра>.js` (+ тест в `tests/`).
2. Экран — `js/games/<игра>.js`: `EC.shell.mount(root, { id, table, extra, primary })` даёт
   панель ставки, `ctx.readBet()`, `ctx.result()`, автоигру; дальше `beginRound` → `round.end`.
3. Строка в `C.GAMES` (с уровнем `lvl`) и `<script>` в `index.html`.

## Прогрессия

**Учёба.** Клик = `1 + Σ(уровень × эффект)` по «Учёбе», доход в секунду = `Σ(уровень × эффект)` по «Быту».
Цена уровня `floor(база × рост^уровень)`: «Учёба» дорожает на 30%, «Быт» — на 15%. Апгрейд появляется
в ведомости, когда наботано 50% его базовой цены. Пока вкладка скрыта или закрыта, доход идёт вполсилы
и не дольше 8 часов. Темп сверен симуляцией (`tools/balance-sim.js`, проверяется тестом):

| Веха | Активный (3 клика/с) | Ленивый (1,5 клика/с) | Цель роадмапа |
|---|---|---|---|
| Первая покупка | 5 с | 10 с | ≤ 10 / ≤ 15 с |
| Первый пассивный апгрейд | 1:50 | 1:40 | ≤ 2:30 / ≤ 3:00 |
| Казино доступно (40 000) | 4:21 | 8:07 | 4:15–6:00 / 8–11 мин |
| 250 000 наботано | 9:44 | 16:49 | ≈ 10 / ≈ 17 мин |

**Казино.** Опыт за раунд: `1 + floor(log10(ставки))`, за победу вдвое. Пороги — таблица `C.LEVEL_XP`
(ур. 2 — 30 XP, 7 — 500, 20 — 4 400). За уровень: очко навыка и `50 × уровень` E.

| Уровень | Открывается |
|---|---|
| 1 | Слоты «Классика», Кости · миссии, чат и лента, достижения казино |
| 2 | Ежедневные квесты |
| 3 | Рулетка · навыки |
| 5 | Блэкджек |
| 6 | Магазин казино |
| 7 | Crash |
| 8 | Недельный ивент |
| 9 | Слоты «Книга Егорика» |
| 10 | Донат Егору |
| 11 | Баккара |
| 14 | Видеопокер |
| 17 | Слоты «Мегавейс» |
| 20 | Холдем |
| 1 000 E выиграно | VIP-уровни |

Запертые столы видны в лобби с замком и прогрессом; системы, которые ещё не открыты, не показываются
совсем. Новичку после сцены — 3 бесплатных спина на «Классике».

## Маркетинг

- **Превью ссылки** (Open Graph / Twitter): картинка `assets/og-image.png` 1200×630 и описание.
- **Карточка «Поделиться»** на редких событиях (Crash ×10+, роял/стрит-флеш, Triple 777, ва-банк,
  MEGA/ULTRA WIN): картинка + готовый текст со своей реферальной ссылкой; «Отправить…» на телефоне.
- **PWA**: `manifest.webmanifest`, иконки, теги для iOS — сайт ставится на главный экран.
- **Реферал** `?ref=Имя`: новичок по ссылке получает 500 E. Ссылку можно скопировать в профиле.
- **Звук джекпота** — отдельный стингер на самые редкие выигрыши.
- **Первые секунды**: тема ставится до первой отрисовки, пока скрипты грузятся — экран загрузки,
  шрифты второй темы подгружаются заранее.
- **«Честные шансы»** — модалка с RTP каждой игры и ссылкой на код.
- **Аналитика** — выключена. Включить: завести бесплатный счётчик на goatcounter.com и вписать адрес
  `https://ИМЯ.goatcounter.com/count` в `C.ANALYTICS.goatcounter`. Считаются экраны и события
  (пропуск, «Поделиться», реферал, покупки в магазине). Без cookie.

## Решения и отступления от роадмапа

- Переключатель режимов подписан **«Депать / Ботать»** (по просьбе автора, вместо «Учёба / Казино»).
- Учебные достижения **без денежной награды**: +100 E за «Первый клик» ломали бы выверенный темп старта.
  Казино-достижения по-прежнему дают +100 E.
- Критический клик («автомат» ×5) из прошлой версии убран — в формулах роадмапа его нет.
- Недельный ивент (с 8-го уровня) умножает и выигрыши казино, и доход на учёбе — как в §4.1.
- Поля казино в сейве остались плоскими (без вложенного `casino: {…}`): новое — блок `progress`, версия 2,
  отказ от хранения производных значений. Переезд полей в `casino` ничего не дал бы игроку, но рисковал сейвами.
- Не сделано (по роадмапу — опционально или не техническое): престиж «Пересдача», свой домен,
  service worker (без него сайт не устаревает в кэше после обновлений).
- Синий БГУИР (`#1B4F9C`) — ориентир из роадмапа, стоит сверить с брендбуком.
