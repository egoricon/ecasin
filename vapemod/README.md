# Vape Mod (Forge, Minecraft 26.2)

Основа — официальный MDK Forge 26.2 (`MinecraftForge/MinecraftForge`, ветка `26.2`, папка `mdk/`).

- Minecraft 26.2, Forge 65.1.3 (`26.2-65.1.3`)
- Java 25 (Minecraft 26.1+ требует Java 25), Gradle 9.5.0 через wrapper

## Запуск

```sh
./gradlew runClient   # клиент с модом
./gradlew build       # jar в build/libs/
```
