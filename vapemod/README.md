# Vape Mod (Forge, Minecraft 26.2)

Вейп, жидкости со вкусами и шкала парения рядом с полоской голода.

- Minecraft **26.2**, Forge **65.1.3** и новее (`26.2-65.1.x`)
- Java **25** (Minecraft 26.1+ работает только на Java 25)
- Основа — официальный MDK Forge 26.2 (`MinecraftForge/MinecraftForge`, ветка `26.2`, папка `mdk/`)

## Установка

1. Поставь Forge для 26.2 через установщик Forge.
2. Положи `vapemod-<версия>.jar` в папку `mods`.
3. Запусти профиль Forge 26.2.

## Как играть

**Вейп** — зажми ПКМ, чтобы затянуться, отпусти, чтобы выдохнуть.

- Пока ПКМ зажата: пара нет, только поза «вейп у губ», светящийся экранчик и тихий звук вдоха.
- При отпускании: звук выдоха и облако пара изо рта по направлению взгляда (видят все игроки рядом).
  Чем дольше затяжка, тем больше и дольше облако и тем сильнее растёт шкала.
- Отпустил раньше ~0,3 с — пара нет, шкала не растёт, жидкость не тратится.
- Максимум затяжки ~3 с, потом выдох происходит сам.
- Каждая завершённая затяжка тратит 1 единицу жидкости (полоска под иконкой вейпа).
- Под водой пара нет.
- Затяжку прерывают смена слота, удар и смерть — пара нет, шкала не растёт.

**Жидкости.** Держать флакон во время парения не нужно: один флакон заливается в вейп и даёт
40 затяжек (остаток видно полоской под иконкой вейпа). Как заправить:

- флакон в основной руке, вейп во второй — ПКМ (так же меняется вкус);
- или в инвентаре возьми флакон курсором и нажми ПКМ по вейпу;
- если вейп пустой и в руке, а флакон во второй руке — просто ПКМ.

Флакон во второй руке не трогает вейп, в котором ещё есть жидкость.

| Жидкость | Эффект | Рецепт (без формы) |
|---|---|---|
| Яблоко | Регенерация | яблоко + сахар + бутылка воды |
| Мята | Скорость | папоротник + сахар + бутылка воды |
| Ягоды | Поглощение | сладкие ягоды + сахар + бутылка воды |

**Вейп** (верстак):

```
 . Ж .
 Ж С Ж      Ж — железный слиток, С — стекло, Р — редстоун
 Ж Р Ж
```

**Шкала парения** — 10 иконок-облачков над полоской голода.

- Растёт при выдохе, медленно падает сама.
- Сохраняется после смерти и перезахода.
- Затяжка при полной шкале → эффект **«Кашель»**: тошнота, замедление, кашель.
- Пустая шкала долгое время (только если ты уже парил) → эффект **«Тяга»**:
  медленнее копаешь и слабее бьёшь. Любая затяжка снимает тягу.

## Конфиг

- `config/vapemod-common.toml` — длительность затяжки, прирост и спад шкалы, жидкость,
  кашель, тяга.
- `config/vapemod-client.toml` — показывать шкалу всегда, смещение шкалы.

## Сборка из исходников

```sh
./gradlew build       # jar в build/libs/
./gradlew runClient   # клиент с модом
```

Текстуры и звуки оригинальные, генерируются скриптами `tools/gen_textures.py` и
`tools/gen_sounds.py`.
